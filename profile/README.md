# Performance

Maya performance depends on polygon count, textures, rigs, simulations, plugins, viewport settings, available RAM, CPU performance, and graphics hardware.

Optimized geometry, efficient textures, cached simulations, and sufficient memory can improve responsiveness when working with large production scenes.

---

# Troubleshooting

If Maya becomes slow or unstable, review graphics drivers, scene complexity, available memory, plugins, scripts, textures, and simulation caches.

For rendering issues, verify renderer configuration, materials, lighting, output settings, available storage, and system resources.

Maintain backups and incremental versions of important project files.
